Wave heights are face height — what the wave looks like from the lineup — with body-scale wording beside it. Set size is the bigger ones in the hour, not the average. Everything is transformed onto this beach's own orientation and slope, so it is a forecast for this stretch of sand rather than for the region.

What this page is for. The top half is instruments and model runs, each one named, timestamped and linked back to its source, so you can read the same numbers a forecaster reads and make your own call. Nothing up there is averaged into a single figure: where two models disagree, you see both lines.

This page’s own opinion is near the bottom, folded away, because it is one reading of the same data rather than the answer — and because it has been wrong in ways worth knowing about. Every run is archived and graded afterwards against the buoy and against sessions the crew actually surfed, so the scoreboard under “how this page has actually done” is the real one, including the misses.
