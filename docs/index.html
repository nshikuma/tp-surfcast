Wave heights are face height — what the wave looks like from the lineup — with body-scale wording beside it. Set size is the bigger ones in the hour, not the average. Everything is transformed onto this beach's own orientation and slope, so it is a forecast for this stretch of sand rather than for the region.

What this page is for. A webcam will always beat a model for what the ocean is doing right now, and nothing here pretends otherwise — the cam links are at the top for exactly that reason. What a cam cannot do is tell you about Thursday. That is the job here: decide tomorrow in thirty seconds, and work out which morning this week is worth keeping free. Every run is archived and graded against the buoy afterwards, so the scoreboard under “how this forecast has actually done” is the real one, including the days it got wrong.
